antcc
=====

A small C compiler using its own independent backend.

  - Supports most of C11 and some C23 features, as well as some common extensions.
  - It can build real-world C codebases such as Lua, SQLite, git, curl, Tcl, DOOM...
  - Compilation speed is fast, and generated code efficiency falls somewhere in the middle of tcc and gcc -O1.
